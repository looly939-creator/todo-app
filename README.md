# 📝 تطبيق قائمة المهام - Todo App

تطبيق ويب احترافي وعملي لإدارة قائمة المهام اليومية مع حفظ محلي (Local Storage) وواجهة تفاعلية جميلة.

---

## ✨ المميزات الرئيسية

### 🎯 إدارة المهام
- ✅ **إضافة مهام جديدة** بسهولة
- ✅ **تحديد حالة المهام** (مكتملة/نشطة)
- ✅ **حذف المهام** الفردية
- ✅ **حذف جميع المهام** أو المهام المكتملة فقط

### 🎨 أولويات ملونة
- 🔴 **عالية الأولوية** (أحمر)
- 🟡 **عادية** (برتقالي)
- 🟢 **منخفضة** (أخضر)

### 🔍 فلترة ذكية
- **الكل**: عرض جميع المهام
- **نشطة**: المهام غير المكتملة فقط
- **مكتملة**: المهام المنجزة فقط
- **عالية الأولوية**: المهام ذات الأولوية العالية فقط

### 📊 إحصائيات فورية
- 📈 إجمالي عدد المهام
- ⏳ عدد المهام المتبقية
- ✔️ عدد المهام المكتملة

### 💾 حفظ محلي (Local Storage)
- 📱 حفظ جميع المهام محلياً في المتصفح
- 🔄 استعادة البيانات تلقائياً عند إعادة فتح التطبيق
- ⚡ لا يتطلب اتصال بالإنترنت

### 📱 متجاوب تماماً
- ✅ يعمل على الهواتف الذكية
- ✅ يعمل على التابلت
- ✅ يعمل على أجهزة الحاسب

## 🚀 كيفية الاستخدام

### الطريقة الأولى: الفتح المباشر
1. **افتح الرابط**: https://looly939-creator.github.io/todo-app/
2. **أضف مهمة**: اكتب المهمة في حقل الإدخال
3. **حدد الأولوية**: اختر من القائمة المنسدلة
4. **اضغط إضافة**: أو اضغط Enter
5. **أكمل مهامك**: اضغط على checkbox لتحديد إنجاز المهمة
6. **احذف إذا لزم**: اضغط زر حذف

### الطريقة الثانية: التحميل المحلي
```bash
# انسخ المستودع
git clone https://github.com/looly939-creator/todo-app.git

# ادخل المجلد
cd todo-app

# افتح الملف بالمتصفح
open index.html
# أو على Windows
start index.html
```

## 💡 الميزات المتقدمة

### 🔐 حفظ البيانات
- جميع المهام تُحفظ تلقائياً في `localStorage`
- البيانات تبقى محفوظة حتى بعد إغلاق المتصفح
- يمكن مسح البيانات بحذف جميع المهام

### ⌨️ اختصارات لوحة المفاتيح
- **Enter**: إضافة مهمة جديدة
- **Click checkbox**: تحديد المهمة كمكتملة

### 🎯 فحص صحة الإدخال
- لا يسمح بإضافة مهام فارغة
- تأكيد قبل حذف المهام المكتملة أو جميع المهام
